# DigitalFutureIA

Somos Ale y Hugo. DigitalFutureIA es nuestro proyecto de herramientas a medida y automatización de tareas web para pymes y autónomos.

[Conoce DigitalFutureIA en nuestra web](https://digitalfutureia.es/).

## En qué trabajamos

Partimos de una tarea concreta: actualizar un catálogo, preparar contenido o recopilar datos para un informe. Primero revisamos el proceso y sus límites. Después acordamos qué construir, cómo comprobar el resultado y qué debe seguir aprobando una persona.

Ale lleva la revisión del proceso, la comunicación y la relación con el cliente. Hugo trabaja en código, datos y construcción técnica.
